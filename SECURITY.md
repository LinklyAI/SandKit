# Security

SandKit processes images in the browser. The sample showcase and editor do not upload images, collect credentials, or provide a server-side image service.

Please do not include secrets or private images in a public issue. For a security vulnerability, use GitHub's private vulnerability reporting feature when enabled on this repository. If it is unavailable, contact the maintainers through the contact channels on [linkly.ai](https://linkly.ai/) to arrange a private report before sharing details.

Include the affected commit, reproduction steps, impact and a minimal non-sensitive example. Only the latest source revision is supported before the first stable release.
